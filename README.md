# 펄스 Pulse

크랙(crack.wrtn.ai) 작품의 대화·좋아요·댓글·대화방과 **정산 예상 현금/캐시**를 하루 몇 번씩 기록해서, 날마다 어떻게 움직이는지 보여 주는 크롬 확장 프로그램이에요. (비공식)

- 이번 달 정산 예상과 **월말 예상·목표 달성 여부**를 첫 화면에서 바로 봐요
- 대화 1천 개당 수익, 작품별 하루 평균 수익과 월말까지 더 늘 몫
- 오리지널 지원금(작품당 한 번)을 따로 셈해서 이번 달 합계에 더해요
- 기록 간격이 들쭉날쭉해도 **하루 단위**로, 또는 **기록 사이 시간당 속도**로 나눠서 보여 줘요
- 작품마다 하루씩 막대와 **변화(▲▼%)**, 작품별 추정 수익
- "작품명"과 "작품명 ˢᵃᶠᵉᵗʸ"를 한 작품으로 묶어서 보기
- 크롬에 로그인된 크랙 계정을 그대로 써요. 하루 1~3번 자동 스냅샷
- 새 버전이 나오면 알려 주고, 버튼 하나로 업데이트

## 설치

1. 오른쪽 위 초록색 **Code → Download ZIP**으로 받아서 압축을 풀어요. 풀린 폴더는 지우지 않을 곳에 둬요.
2. 크롬 주소창에 `chrome://extensions` (엣지는 `edge://extensions`, 웨일은 `whale://extensions`)
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 풀린 폴더(`manifest.json`이 들어 있는 폴더)를 고르기
5. 퍼즐 아이콘에서 펄스를 고정해 두면 편해요

## 업데이트

새 버전이 나오면 대시보드 왼쪽 아래와 팝업에 **새 버전 업데이트** 버튼이 떠요. 누르고, 처음 한 번만 펄스가 설치된 폴더를 골라 주면 바뀐 파일만 받아서 바꿔 넣고 다시 켜져요. 기록과 설정은 그대로예요.

## 주의

비공식 API를 써요. 몇 분마다 받으면 크랙이 요청을 막을 수 있어서 자동 스냅샷은 하루 3번까지만 고를 수 있고, 막히면 3시간 쉬어요. 기록은 브라우저 안에만 저장되니 가끔 **기록 → 전체 내보내기**로 백업해 두세요.

# 바뀐 점

## v2.3.0 — 오리지널 지원금
- 오리지널 작품마다 한 번 받는 지원금(기본 30만 원)을 따로 셈해요. 언세이프와 세이프 버전은 한 작품으로 셈
- 이번 달 받는 지원금을 월말 예상에 더해서 "합쳐서 월말"로 보여 주고, 목표에도 넣어 계산해요
- 받은 달은 생성 달로 짐작하고, 기록 중에 새로 오리지널이 된 작품은 그 달로 자동으로 잡아요. 작품마다 바꾸거나 뺄 수 있어요
- 정산 예상 현금에 이미 들어가 있다면 스위치를 켜서 따로 더하지 않게 할 수 있어요
